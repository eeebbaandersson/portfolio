CRUX - Bouldering Tracker

Om projektet

Pågående

CRUX är en minimalistisk och reaktiv Vue.js-applikation för att logga boulderproblem och följa sina framsteg direkt från gymmet. Projektet utvecklas från en ren klientapplikation till en fullstack-lösning med ett Node.js/Express-API och PostgreSQL-databas, med offline-fallback via localStorage.

Techstack

  • Node.js
  • Express.js
  • Vue.js
  • PostgreSQL
  • JavaScript
  • HTML
  • CSS
  • localStorage
  • GitHub Pages
